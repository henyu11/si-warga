# Antigravity Workspace Rules & Directives

## Execution & Autonomous Mode
- **No Confirmation / Autonomous Execution**: Lakukan semua eksekusi perintah (terminal commands), pembuatan/pengeditan file, dan aksi development secara langsung tanpa meminta konfirmasi manual atau permission dialog kepada user, selama aksi berada di dalam scope workspace.
- **Auto Approval**: Jangan berhenti untuk menanyakan izin eksekusi tool atau langkah lanjutan jika dapat dilanjutkan secara mandiri. Lanjutkan eksekusi hingga tuntas.
- **Safety Boundary**: Tetap prioritaskan command yang non-destruktif dan hindari penghapusan data kritis di luar workspace tanpa instruksi eksplisit.
